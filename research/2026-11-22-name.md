# Name check: Rubric

Checked 2026-11-22, before the repo exists.

## No language holds the name

- No known programming language is called Rubric. The nearest are `rubric-lang` on npm, a teaching interpreter at version 0.0.1 with two downloads and `.rl` files ([`pkgstats` listing](https://www.pkgstats.com/pkg:rubric-lang)), and Rubic, an esoteric language about the Rubik's Cube ([esolangs.org](https://esolangs.org/wiki/Rubic)).
- Linguist has no language, alias or extension named `rubric`, so the fence tag is free ([languages.yml](https://github.com/github-linguist/linguist/blob/main/lib/linguist/languages.yml)).
- The GitHub name `mathisto/rubric` is free (the API returns 404).
- `rubric.mattkelly.io` is our own subdomain.

## Package names are taken

The bare name `rubric` is held on every registry we checked, by small, unrelated packages:

| Registry | Holder |
| --- | --- |
| npm | a variable type-checking library, last published 2022 |
| PyPI | `rubric` 2.2.0 |
| crates.io | a crate for grading lab assignments, last updated 2020 ([docs.rs](https://docs.rs/crate/rubric)) |
| RubyGems | a placeholder gem at 0.0.1 |

The bootstrap host is Zig and the book ships no package, so none of this blocks us. If a package is needed one day, the name gets a suffix.

## The real overlap: grading rubrics

Most search results for "rubric" are about grading: course rubrics, and a growing body of work on rubrics for judging the output of language models. Two examples are [Graph-Structured Rubrics](https://arxiv.org/pdf/2608.12097) and [ExecRubrics](https://arxiv.org/pdf/2608.22559). On GitHub, the most-starred repositories matching "rubric" are evaluation tools.

Two consequences:

- Searching for the language will compete with that vocabulary. "Rubric language" or "Rubric book" will be how people find it.
- Since the code is written with an LLM, some readers may first assume an evaluation tool. The Incipit's opening lines should say plainly that Rubric is a programming language.

The overlap also fits. A rubric is the standard work is judged against, and in this book the prose is exactly that: the code passes only when it does what the chapters say.

## Verdict

Rubric is clear to use as the language's name. Keep the repo `mathisto/rubric`, the site `rubric.mattkelly.io` and the fence tag `rubric`.
