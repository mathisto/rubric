# Bootstrap host: Zig 0.17.1

Pinned 2026-11-22, before the repo exists. Zig only bootstraps the language; it is frozen at one tagged release and changes only by a decision of its own.

## The release

- **Version:** 0.17.1, released 2026-11-02. It is the newest tagged release. `master` is at 0.18.0-dev and is not used.
- **Where Zig lives now:** development moved from GitHub to Codeberg; the GitHub releases stop at 0.15.1. The download index at `https://ziglang.org/download/index.json` and the signed files beside it are the source of truth.
- **Release notes:** a patch release has no notes page of its own; 0.17.0's notes cover the series ([0.17.0 release notes](https://ziglang.org/download/0.17.0/release-notes.html)).
